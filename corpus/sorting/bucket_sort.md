# Bucket Sort

Bucket sort is a distribution-based sorting algorithm that partitions an array into a fixed number of uniformly spaced buckets, sorts each bucket individually using another algorithm or recursive calls, and concatenates the buckets to form the final sorted sequence.

## Distribution and Collection Mechanics

Assuming input elements are uniformly distributed across an interval [0, 1), bucket sort creates k empty buckets. Each element arr[i] is mapped to bucket index floor(k * arr[i]). Once all n elements are distributed, each non-empty bucket is sorted using an efficient algorithm such as insertion sort. Finally, the sorted buckets are concatenated in sequential index order.

## Mathematical Average Runtime

When the input values are generated by an independent, uniform random distribution, the expected number of elements falling into each bucket is n / k. If k is chosen proportional to n (for example, k = n), the expected time to sort each bucket with insertion sort is O(1). Consequently, the overall average-case time complexity is linear O(n).

## Worst-Case Degradation and Memory

If the input distribution is skewed such that all or most elements cluster into a single bucket, the algorithm degrades to the worst-case complexity of the underlying bucket sorting routine, typically O(n^2) for insertion sort. Bucket sort requires O(n + k) auxiliary memory to hold the bucket pointer chains.
